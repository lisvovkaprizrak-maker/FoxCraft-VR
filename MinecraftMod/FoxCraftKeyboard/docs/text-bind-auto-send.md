# Текстовые бинды: отправлять сразу

## Требование
В интерфейсе биндов добавить галочку **«Отправлять сразу»** для каждого текстового бинда.

- **Выключено** (по умолчанию): нажатие назначенной кнопки вставляет весь текст бинда в активное поле чата; Enter **не** вызывается. Можно отредактировать текст перед отправкой.
- **Включено**: то же нажатие вставляет полный текст бинда, после успешной вставки вызывает ровно **один** Enter. Не отправлять пустую строку.
- Значение настройки сохраняется и загружается вместе с конкретным биндом.
- Не инициировать отправку после одиночных букв, пробелов, каждого свайп-слова или обычного ручного набора.
- При отсутствии активного поля чата ничего не вводить и не отправлять.
- Не менять физические привязки левого/правого триггеров Quest 3.

## Приёмочные тесты
1. Текстовый бинд «Привет» с выключенной галочкой: появляется `Привет`, без Enter.
2. Тот же бинд с включённой галочкой: появляется `Привет`, затем один Enter.
3. Повторное открытие настроек сохраняет галочку.
4. Нажатие вне чата и пустой бинд не отправляют сообщений.
5. Свайп и обычная клавиатура по-прежнему не отправляют текст автоматически.

**Статус:** спецификация. В текущей ветке ещё нет подсистемы текстовых биндов, поэтому этот документ не означает, что переключатель уже работает в JAR.
