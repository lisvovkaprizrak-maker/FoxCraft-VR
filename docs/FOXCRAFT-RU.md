# 🦊 FoxCraft VR — состояние разработки

FoxCraft VR — экспериментальная пользовательская сборка на базе открытого проекта QCXR-XR-Wrapper. Цель — подключить системную клавиатуру Meta Quest к Minecraft-чату через Unity ↔ Fabric-мост, не заменяя оригинальную QuestCraft на устройстве.

## Подтверждено

- Исходный форк содержит Unity-проект с папками `Assets`, `Packages`, `ProjectSettings`.
- Проект использует **Unity 2022.3.62f3** и **OpenXR 1.14.3**.
- Прежние тесты Fabric на Quest 3 подтвердили обнаружение чата и вставку тестового русского текста. Это **не** подтверждает работу системной клавиатуры Meta.

## Текущий этап

Ветка `foxcraft/preflight-and-integration` сначала добавляет безопасную проверку структуры проекта и его версий. Workflow **FoxCraft preflight** запускается без Unity, без Unity-лицензии и без секретов. Он **не собирает APK**.

После успешной проверки предстоит добавить и скомпилировать Unity-мост, Pojlib, Android-манифест, настройки бренда и систему сборки. Клавиатуру необходимо проверить непосредственно на Quest 3.

## Безопасность

- Не добавляйте в GitHub файлы Unity-лицензии, пароли, токены или ключи подписи.
- Оригинальную QuestCraft и сохранения миров не удаляйте.
- Пока APK FoxCraft не существует, не пытайтесь устанавливать исходный ZIP как приложение или Minecraft-мод.
- FoxCraft — не официальный проект Meta или команды QuestCraft; необходимо соблюдать условия лицензий исходных компонентов.
