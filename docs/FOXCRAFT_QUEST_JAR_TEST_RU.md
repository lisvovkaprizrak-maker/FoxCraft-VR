# FoxCraft VR — проверка клавиатуры на настоящем Quest

**Текущий артефакт:** `foxcraft-keyboard-0.1.0-alpha.jar`, Minecraft Java **1.21.5**, Fabric Loader и Fabric API, Java 21. Не APK. Его можно добавить в установленный QuestCraft, пока отдельная сборка Unity FoxCraft не готова.

## Перед тестом

1. Сохрани копию важных игровых миров и настроек.
2. Открой QuestCraft и выбери **профиль Minecraft 1.21.5 с Fabric**. Другие версии и Vanilla/Forge для этого мода не подходят.
3. Убедись, что Fabric API установлен. Он может присутствовать в стандартном профиле QuestCraft.
4. Закрой Minecraft и добавь скачанный `foxcraft-keyboard-0.1.0-alpha.jar` именно в папку `mods` выбранного профиля. В зависимости от версии QuestCraft это делается через управление модами или файловый менеджер. Не переименовывай `.jar` в `.apk` и не пытайся устанавливать JAR как приложение.
5. Убери **старые копии FoxCraft Keyboard** из того же профиля. Не удаляй Vivecraft или Fabric API.
6. Запусти профиль 1.21.5. На первом тесте безопаснее использовать отдельный тестовый мир.

## Проверка в шлеме

- **Чат:** появление клавиатуры, правильное размещение ниже чата, отсутствие перекрытия текста.
- **Набор:** RU/EN, верхние цифры 1–0, пробел, Backspace, Enter, специальные символы при долгом нажатии, ё/Ё.
- **Управление:** наведение и нажатия правым и левым контроллером; клавиши и рамка подсвечиваются оранжевым.
- **Свободная клавиатура:** переключение режима, перемещение в пространство, продолжение движения/управления миром, клавиши F1–F12, Ctrl/Shift/Alt.
- **Безопасность мира:** если лазер/курсор на клавиатуре и происходит нажатие, позади неё **не должен разрушаться или ставиться блок**. При наведении мимо клавиатуры обычное взаимодействие с миром должно работать.
- **Настройки:** шестерёнка, размер 50–100%, наклон, темы, сброс положения/параметров; закрытие и повторное открытие клавиатуры и перезапуск QuestCraft для проверки сохранения.
- **Чаты и меню:** открытие обычного чата, команд через /, поля ввода других окон; клавиатура не должна загораживать кнопки.

## Если что-то не работает

Не удаляй миры или всю папку QuestCraft. Сначала убери только FoxCraft JAR из тестового профиля, чтобы проверить запуск без мода. При ошибке загрузки Minecraft открой QuestCraft **Need Help?** и сохрани `latestlog.txt`/ссылку на журнал. В сообщении разработке укажи модель Quest/Pico, версию QuestCraft, Minecraft (строго 1.21.5), что было нажато и что произошло. Если можно, приложи скриншот или короткое видео.

## Ограничения

Это экспериментальный мод: успешная проверка сборки Java и Fabric не доказывает совместимость с конкретным Vivecraft/QuestCraft на шлеме. Он не устанавливает полное приложение FoxCraft, не меняет лаунчер и не добавляет телефонный 2D-движок Minecraft.
